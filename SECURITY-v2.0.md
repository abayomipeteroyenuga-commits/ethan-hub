# Ethan Hub v2.0 — Protected Global Access
Allowed: Student, Professional, Business Owner, Instructor, Admin, Super Admin.
Public signup: Student, Professional, Business Owner only.
Staff roles must be administratively assigned.
Dashboard and connected-service SSO launch require an authenticated Ethan ID and an allowed role.
For production privileged authorization, use protected server-side profile/claims rather than editable browser metadata alone.
