# Ethan Hub v2.4 — Super Admin User Management
Adds a practical Super Admin user-management console:
- View all Ethan ID profiles
- Total, approved, pending and Super Admin counters
- Filter approved/pending accounts
- Search by user ID or role
- Approve, update roles and revoke access
- Refresh user list
- Protect the currently signed-in Super Admin from accidental self-revocation/demotion
- Keeps v2.3 approval recognition and existing Ethan SSO integrations

No new database migration is required beyond the existing v2.2 Super Admin RLS policies.
